# 🖋️ RehBook — Твой цифровой манускрипт

[![GitHub Pages](https://img.shields.io/badge/Live-Demo-brightgreen.svg)](https://smachnireh.github.io/rehbook/)
![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Version](https://img.shields.io/badge/Version-15.0-orange.svg)

**RehBook** — это профессиональное автономное веб-приложение для писателей, авторов романов и сценаристов. Оно сочетает в себе эстетику классического бумажного блокнота и современные технологии оптимизации текста.

---

## ✨ Основные особенности

*   **📚 Мультибук-система:** Пишите несколько книг параллельно. Каждая книга имеет изолированный список глав и страниц — вы никогда ничего не перепутаете.
*   **📜 Идеальная тетрадная сетка:** Текст не просто находится на странице, он «лежит» на линиях. Вертикальный ритм выверен до пикселя.
*   **📟 Умная автопагинация:** Система Reflow следит за заполнением листа в реальном времени. Как только место заканчивается, RehBook аккуратно переносит текст на новую страницу.
*   **🖨️ PDF-печать (WYSIWYG):** Экспорт в PDF полностью сохраняет вид приложения: желтоватую бумагу, красные поля и нумерацию. Заголовок главы печатается только на первой странице главы.
*   **🤖 AI-Оптимизация:** Экспорт в формате AI-Compressed удаляет лишние пробелы и пустые строки, используя маркер `¶` для сохранения структуры диалогов. Это экономит до 30% токенов при работе с ChatGPT/Claude.
*   **💾 Безопасность данных:** Автосохранение в `LocalStorage` дополняется возможностью создавать локальные JSON-бэкапы всей вашей библиотеки на компьютер.

## 🚀 Инструкция по использованию

### 1. Начало работы
*   Откройте [RehBook](https://smachnireh.github.io/rehbook/).
*   В левой панели **"Книги"** нажмите `+`, чтобы создать свой первый проект.
*   Выберите книгу и в соседней панели **"Главы"** нажмите `+`. 

### 2. Процесс написания
*   **Фокус-режим:** Нажмите кнопку `≡` в тулбаре, чтобы скрыть боковые панели и остаться наедине с текстом.
*   **Листание:** Вы можете свободно скроллить страницу колесиком мыши. Для перехода между страницами используйте стрелки `←` и `→` в нижней панели навигации.
*   **Автосохранение:** Просто закройте вкладку, когда закончите — RehBook запомнит не только текст, но и конкретную страницу, на которой вы остановились.

### 3. Сохранение и Бэкап
*   **PDF:** Нажмите "Сохранить PDF". В настройках печати браузера **обязательно** включите опцию **"Фоновая графика"** (Background Graphics), чтобы сохранить стиль бумаги.
*   **Бэкап:** Раз в несколько дней нажимайте кнопку **"Бэкап (JSON)"**. Это скачает файл со всеми вашими книгами. Если вы очистите историю браузера, вы сможете восстановить всё содержимое через кнопку **"Импорт"**.

### 4. Работа с ИИ (LLM)
*   Если вы используете нейросети для редактуры, нажмите **"Экспорт"** -> **"AI-Compressed"**. Скопируйте полученный монолитный блок текста — это позволит ИИ обработать больше информации за один запрос.

## 🛠️ Технологии
*   **Pure JS/HTML/CSS:** Без внешних библиотек и зависимостей.
*   **LocalStorage API:** Для мгновенного сохранения состояния.
*   **CSS Print Profile:** Для точной генерации PDF-документов формата A4.

---

## 📂 Как запустить локально?
Просто скачайте файл `index.html` (или `rehbook.html`) из этого репозитория и откройте его любым современным браузером. Приложение будет работать полностью офлайн.

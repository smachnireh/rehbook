# 🖋️ ScribeMind Pro — Твой цифровой манускрипт

[![GitHub Pages](https://img.shields.io/badge/Live-Demo-brightgreen.svg)](https://smachnireh.github.io/rehbook/)
![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Version](https://img.shields.io/badge/Version-12.0-orange.svg)

**ScribeMind Pro** — это полностью автономное веб-приложение для писателей, сценаристов и авторов визуальных новелл. Оно превращает ваш браузер в эстетичный винтажный блокнот с мощными функциями современной верстки.

---

## ✨ Основные особенности

*   **📜 Эстетика бумажного листа:** Интерфейс имитирует реальную записную книжку с линовкой. Текст идеально ложится на строки благодаря выверенному вертикальному ритму.
*   **📟 Автоматическая пагинация:** Приложение само следит за заполнением листа. Как только вы дописали до конца, оно автоматически создаёт новую страницу и переносит фокус.
*   **🖨️ Профессиональный PDF-экспорт:** Сохраняйте свои книги в формате A4. Приложение автоматически расставляет сквозную нумерацию и выводит заголовок главы только на её первой странице.
*   **🤖 AI-Compressed Export:** Специальный режим для работы с нейросетями (ChatGPT/Claude). Сжимает текст, удаляя лишний "мусор" и экономя до 30% токенов, сохраняя при этом структуру диалогов (символ `¶`).
*   **💾 Полная автономность:** Приложение состоит из одного HTML-файла. Все данные сохраняются локально в вашем браузере (`LocalStorage`) — интернет не нужен.

---

## 🚀 Быстрый старт

1.  **Откройте приложение:** Перейдите по ссылке [smachnireh.github.io/rehbook/](https://smachnireh.github.io/rehbook/).
2.  **Создайте проект:** В левой панели нажмите `+` в разделе "Книги".
3.  **Добавьте главу:** Нажмите `+` в разделе "Главы".
4.  **Начните писать:** Просто вводите текст. Если лист закончится, страница перевернётся автоматически.

## 🛠️ Инструкция по использованию

### Управление страницами
*   Используйте **стрелки (← →)** внизу экрана для навигации между страницами одной главы.
*   Номера страниц внизу листа — это **глобальная нумерация** всей книги. Она автоматически пересчитывается при добавлении текста.

### Сохранение в PDF
1.  Нажмите кнопку **"Сохранить PDF"** в верхней панели.
2.  В открывшемся окне печати выберите принтер: **"Сохранить как PDF"**.
3.  *Важно:* Убедитесь, что в настройках печати включена опция **"Фоновая графика"** (Background Graphics), чтобы сохранился цвет бумаги и линии.

### Экспорт для ИИ
Если вы хотите скопировать текст книги для анализа в ChatGPT:
1.  Нажмите **"Экспорт Текста / AI"**.
2.  Выберите вкладку **"AI-Compressed"**.
3.  Нажмите **"Скопировать"**. Этот формат позволяет передать ИИ больше контекста за меньшие деньги/токены.

### Скрытие меню
Нажмите иконку **"≡"** в левом верхнем углу, чтобы скрыть боковые панели и сосредоточиться только на тексте (Focus Mode).

## 🛠️ Технологический стек

Приложение написано на "чистом" стеке без использования тяжелых библиотек:
*   **HTML5** (семантическая верстка)
*   **CSS3** (Flexbox, Grid, Media Queries для печати)
*   **JavaScript** (Native JS, LocalStorage API, DOM Manipulation)
